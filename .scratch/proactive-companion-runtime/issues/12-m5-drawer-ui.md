## Notes

目标：把 M1–M5 已经落库的调度、记忆、生活事件与用量账本呈现给用户，作为调参依据。本票只做只读展示，不加入任何原型控制、写接口或新的数据形状。

约定：

- **复用现有接口**：`debug/ticks`、`memory`、`today`、`usage`；不新增抽屉专用接口，也不把四个接口合流，避免复制业务逻辑。
- **页签只在打开时读取**：关闭后不轮询；现有 SSE 已负责聊天与用量角标，抽屉不做实时推送。
- **文案边界**：状态仍只用“醒着 / 在忙 / 不方便”；技术原因翻译成 spec D-3 的中文抽屉文案，不把 `decision_reason` 原样暴露成英文。
- **原型页签移除**：原型里的“原型控制”及其所有模拟按钮不进生产。
- **无时间 API**：页面不调用 `Date.now` / `new Date` / timer；时间直接截取接口返回的 ISO 字符串展示。
- **失败隔离**：四个 fetch 用 `Promise.allSettled`；单个失败只显示该页签的空态/失败态。
