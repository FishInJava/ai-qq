【定义】
1. 有效编码量：排除空行、注释、自动生成代码后的新增/修改代码量，或按功能点/接口/页面折算。
2. 应执行时间 = 有效编码量 / 历史编码速度 × 复杂度系数 + 调试/测试/Review 缓冲。
3. 返工：已生成或已提交的代码因需求变更、上下文不足、方案错误、接口不匹配、测试后置、规范问题、环境问题等被重写、删除或大改。
4. 返工 Token：因返工而重复生成、重复解释、重复调试所消耗的 Token。
5. Token 产出效率 = 有效代码行 / 总 Token（可换算为“有效代码行/千Token”）。
6. 返工 Token 占比 = 返工相关 Token / 总 Token。
