# 在旁边 · 主动陪伴原型

基于 `../主动陪伴AI聊天助手_PRD_V1.0.md` 制作的可交互 HTML 原型。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `index.html` | 唯一运行文件。单文件、内联 CSS/JS、无外部依赖，双击即可打开 |
| `screenshots/` | 最终版状态截图，仅作验收参考，运行时不需要 |
| `README.md` | 本说明 |

截图包含：桌面初始、用量抽屉、导入预览、390px 移动端、移动端角色库、深色主题。

## 打开方式

直接双击 `index.html`，或：

```powershell
start prototype\index.html
```

不需要安装依赖或启动服务，可离线运行。

## 已实现的核心流程

- 角色库：3 个示例角色、搜索、未读/状态/主动次数
- 对话：流式回复、碎片化多气泡、失败与「再发一次」
- 三态：醒着、在忙、不方便；恢复后的时间断层与「好转」语气
- 主动消息：自动到达、手动模拟 tick、预算剪枝、生活事件/事实双锚点、tick 留痕
- 额度：70% 警告、100% 置灰、续额后恢复；轮换角色时保留各自草稿
- 导入卡：示例卡、重复卡、损坏卡、字段预览、覆盖/新建
- 细节抽屉：调度、记忆、她的今天、用量、原型控制
- 适配：深色主题、390px 窄屏、键盘焦点、Escape 关闭、减少动效

## 演示入口

右上角「细节」→「原型」Tab：

- 额度记为 70%
- 额度耗尽
- 切换主动开关
- 清空角色库（查看首次导入空态）
- 重置全部演示
- 模拟一次 tick
- 下一次回复失败
